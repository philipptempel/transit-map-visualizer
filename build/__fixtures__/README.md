# Test fixtures

Hand-written, made-up responses in the shape the real sources return. They describe the
fictional Demostadt, not any real place, and no map data is built from them.

- `overpass-demostadt.json`: an Overpass `out body` answer with two tram routes in one
  route_master (one per direction, one way drawn against the direction of travel), an
  express bus that only has platforms, a commuter train, a stop_area with a station node,
  two stops that share a name 80 m apart, and a third stop with that name 2 km away.
